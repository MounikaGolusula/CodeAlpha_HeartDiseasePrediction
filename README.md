# Heart Disease Prediction using Machine Learning

## Project Overview

This project predicts the likelihood of heart disease using patient medical information. A Random Forest Classifier was trained on a Heart Disease dataset using Scikit-learn and deployed through a Streamlit web application.

## Features

* Heart Disease Prediction
* Random Forest Classifier
* Model Evaluation
* Saved Trained Model using Joblib
* Interactive Streamlit Web Application
* Clean Project Structure

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Joblib

## Dataset Features

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise Induced Angina
* Oldpeak
* Slope
* Number of Major Vessels
* Thal

## Model Used

Random Forest Classifier

## Evaluation Metrics

* Accuracy Score
* Classification Report
* Confusion Matrix
